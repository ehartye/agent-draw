# Drawn firing poses

Four original side-view drawings from the Dust & Decay craft revision: brace, fire, recoil and recovery. Every frame is a complete editable Agent Draw project with its own contours; none uses transform animation. Palette separates blue/slate clothing, warm leather, skin and metal rather than tinting everything sepia.

Render with the managed launcher:

`node scripts/run-managed.js sequence examples/drawn-fire/manifest.json --out output/drawn-fire`

Canvas: 160×192, intended foot origin (80,180). The engine target body height is about 64 pixels; inspect these drawings beside the actual doorway/building before approving scale. Independent art review accepted this as a restrained shot: the support elbow forms a readable V, the hand meets the pistol, the barrel remains near-horizontal, and recoil/return are visible while the lower body stays planted. It is not a demonstration of broad expressive locomotion or the full game's visual/timing acceptance.
